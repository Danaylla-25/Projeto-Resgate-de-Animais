# Projeto-Resgate-de-Animais
# Simulador em Kotlin

Simulador de Resgaste de Animais, desenvolvido para a disciplina de " Programação Mobile Coding".

## Sobre o Projeto
O estudo de caso escolhido para este simulador foi um **Sistema de Gestão Diária para um Abrigo de Animais**. 

O programa simula a rotina de um abrigo, permitindo controlar a entrada de novos animais resgatados (respeitando uma capacidade máxima de 20 animais), registrar adoções e, principalmente, gerenciar o estoque de alimentação. O grande diferencial do simulador é a passagem de dias: o sistema calcula o consumo de ração automaticamente com base na espécie de cada animal, alerta o usuário quando a comida está acabando e processa doações semanais de forma automática.

## Funcionalidades
- Painel de status com controle de dias, lotação máxima e estoque de ração.
- Cadastro completo de animais com validação de dados e verificação de chip único.
- Listagem detalhada dos animais abrigados.
- Simulação de passagem de dias, com desconto automático de ração e alertas de estoque.
- Sistema de adoção que remove o animal selecionado do abrigo.

## Como Executar
